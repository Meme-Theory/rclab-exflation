## Core Research Program

### The Problem Lizzi Solved

The Chamseddine-Connes **cutoff spectral action** was **non-renormalizable**:
1. High-energy boson propagators diverge as p⁴ (don't decrease)
2. Required four-fermion interactions (non-renormalizable)
3. Physical constants depended on cutoff scale unnaturally
4. Asymptotic expansions of heat kernel didn't converge

### Lizzi's Solution: Zeta Spectral Action

$$S_\zeta = \zeta_D(0) = a_4(D^2)$$

is the **zeta function regularization**:
1. Contains ONLY dimension-≤4 operators (renormalizable)
2. No cutoff function ambiguity
3. Proper high-energy behavior
4. All operators determined by Dirac operator D structure
5. Neutrino Majorana mass plays fundamental role

**Impact**: Elevated spectral action to fundamental theory (valid up to Planck scale).

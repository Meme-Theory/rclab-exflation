### C4: Sub-question (d) — Admissible composite-formulation taxonomy (ratio-of-ratios / sum-of-sums)

**Key finding (constructive payload)**: The admissibility of a composite bridge map at a substrate-distance pole is decided by a single discriminant — **homogeneity-degree matching between the composite and its canonical anchor**. A composite `B = f ⊙ g` is admissible iff deg(B) = deg(anchor). This gives a clean three-class taxonomy: ratio-of-ratios (ADMISSIBLE), sum-of-sums-at-equal-degree (ADMISSIBLE), ratio-times-sum (FORBIDDEN). The §VII.BA F-functor reconstruction (CF-S93-W2-1) and the α_s direct-Connes-Karoubi recovery (CF-S94-W1-6) must adopt a degree-matched formulation; the §W1-4/§W2-3 FAILs are the negative class of this taxonomy.

**The discriminant, derived.** Let the canonical Level-3 anchor have homogeneity degree d_A (for the §VII.AU HKR-class anchor, d_A = 0, the cohomology-class ratio; for the §VII.BA Δ_BCS anchor, d_A = +1 in [M_KK^1], §W2-3 Definition 2 WP line 207). A composite bridge map B(L_max) can converge to that anchor under L_max-truncation only if its homogeneity degree equals d_A:

```
(C4.1)   B admissible  ⟺  deg(B) = deg(anchor) = d_A      [degree-matching discriminant]
```

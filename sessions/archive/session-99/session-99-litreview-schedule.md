## Conventions (apply to every dispatch)

1. **Sources**: the folder `00-INDEX.md` is the primary source (curated, content-verified summaries + framework angles). The PDFs sit beside each index for spot-verification; per `feedback_research-corpus`, paper content comes from fetched sources only — the on-disk PDFs ARE the fetched sources.
2. **Indexes are idea-generators, not registers** (`feedback_investigation-material-docs`): the sweep predates the S99 gate landings in places (e.g. G3's Σm_ν gate discussion predates the S99 W3-2 PASS). Every framework-state claim must be anchored to canonical via knowledge MCP (`search_knowledge` / `get_constant` / `trace_entity`) before being treated as live; stale claims are flagged, not silently inherited, and the source index is NOT reconciled.
3. **Review neutrality** (`feedback_review-dispatch-no-orchestrator-angle`): each invocation passes ONE `--context` to all its agents — same sources, same focus, independent reports. No per-agent angles anywhere in this schedule.
4. **Output naming**: `--output sessions/archive/session-99/session-99-litrev-{group}` → per-agent files `session-99-litrev-{group}-{agent}.md`. Collision-checked 2026-06-04: no `session-99-litrev-*` files exist (the default `session-99-{agent}-synthesis.md` paths are TAKEN by the S99 fermion-mass campaign — explicit `--output` is mandatory).
5. **Per-report deliverable**: per-paper adjudication (framework angle confirmed / sharpened / stale / wrong) + candidate validation angles as 4-field carry-forward specs (what / inputs / gate / effort). No verdict-line emission, no registry edits, no computation — review reports only.
6. **Dispatch discipline** (`feedback_dispatch-discipline`): ≤8 concurrent agents per wave; run waves sequentially R1 → R2 → R3 → R4 (R3 consumes R1 outputs; R4 consumes everything). Within a wave, launch all invocations as one batch and wait for ALL before proceeding.

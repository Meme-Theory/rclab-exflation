# Substrate dynamics are NOT bounded by c

1. **Propagation ACROSS the substrate** (signals moving on the emergent 4D metric g_M): bounded by c_Gold ~ 0.915 M_KK. This is where c is a speed limit.

2. **Substrate dynamics** (fold transit, instantons, Jensen evolution, spectral-action gradients): NOT bounded by c. These are not moving through anything -- they ARE the substrate.

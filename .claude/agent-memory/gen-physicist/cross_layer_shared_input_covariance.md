When a session asks whether a joint-evidence MULTIPLICATION across spectral-moment layers (a₀×a₂×a₄) is valid, the crux is almost always **ALGEBRAIC independence (Wronskian / functional independence of the moments) ≠ STATISTICAL independence of the borrowed-input observational residuals**. Keep that distinction razor-sharp; it is the thing the downstream restriction-edit conditions on.

**Why:** S96 W7-7a (D3). The capstone §7.3 multiplied improbabilities across a₀(w₀)×a₂(σ₈)×a₄(m_H) "independent by the certified Wronskian" (S75 W2-E, `W∝R_K′³=e^{−12τ}(e^{3τ}−1)⁶≠0` off τ=0). That certificate licenses only ALGEBRAIC independence (the Seeley-DeWitt moments are functionally independent functions of τ). But the dagger rows borrow the container-observer's FRW H(t) (caveat C10, `ρ_vac∼M_Pl²H²`). A shared external input re-couples the residuals.

**How to apply (the recipe):**
1. Each residual `res_i := X_i_obs − X_i_FW`. Only the FW side borrows the shared input ⇒ `∂(res_i)/∂(ln H) = −∂(X_i_FW)/∂(ln H)` (obs anchors are fixed data).
2. Compute each layer's sensitivity `s_i`. Layers that borrow the input → s_i≠0; layers that are a substrate-IS spectral read-off decoupled from the input → s_i=0 EXACTLY (here m_H, a KK-threshold fiber mass).
3. The shared-input channel is **rank-1**: `Cov = s·sᵀ·Var(δ ln H)`. The normalized off-diagonal correlation is then `Corr(i,j) = s_i s_j/(|s_i||s_j|) = sign(s_i·s_j)` — magnitudes and Var cancel (Sage: `s0*s2/sqrt(s0^2*s2^2)` = `sign`). So in the PURE shared-input channel any two input-sensitive layers correlate at ±1 by construction. This is the PRE-REGISTERED answer (the plan's substitution chain expects `Corr=sign(∂X_i/∂H·∂X_j/∂H)`), NOT a modeling artifact — do not "soften" it.
4. Band: <0.1 PASS / 0.1–0.5 INFO / >0.5 FAIL. Same-sign sensitivities ⇒ |Corr|=1 ⇒ FAIL ⇒ restrict the joint-BF to the zero-parameter spine (the observables with NO borrowed input).
5. Make the band UNAMBIGUOUS in BOTH the verdict `value=` field AND the WP (the restriction-edit gate reads the verdict line; the workshop reads the number). I put `max_offdiag_corr=…_BAND=…` literally in `value=`.

**Substrate-first framing that survives a FAIL:** the FAIL does NOT weaken the substrate Decoupling Theorem (algebraic independence is untouched, a substrate-IS fact). What fails is the LABORATORY-IN multiplicativity through the shared borrowed-H projection. The spine that does not pass through that projection stays multiplicative. Frame as "the borrowed-H map re-couples what the substrate decoupled," not "the layers aren't independent."

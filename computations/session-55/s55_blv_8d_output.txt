========================================================================

Starting from the wave equation for perturbation theta_1 in a
barotropic irrotational fluid at rest (v=0, homogeneous):

  rho/c_s^2 * d_t^2 theta_1 - rho * nabla^2 theta_1 = 0

In d = n+1 spacetime dimensions (n spatial), the acoustic metric
is ds^2 = -A*dt^2 + B*dx_i*dx^i, with A and B determined by:

  Condition I:   B^{n/2}/sqrt(A) = rho/c_s^2
  Condition II:  sqrt(A) * B^{(n-2)/2} = rho

Solution:
  B = (rho^2/c_s^2)^{1/(n-1)}
  A = rho^{2/(n-1)} * c_s^{2(n-2)/(n-1)}

Acoustic scale factor: a^2 = B = (rho/c_s)^{2/(n-1)}
                       a   = (rho/c_s)^{1/(n-1)}

For constant rho:
  a propto c_s^{-1/(n-1)}
  N_e = 1/(n-1) * ln(c_s_i/c_s_f)

Since n = d-1 (spatial dims = spacetime dims - 1):
  N_e = 1/(d-2) * ln(c_s_i/c_s_f)

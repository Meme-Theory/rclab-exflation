## §1 — Schema specification

**Scope axis** (durability-promotion ladder):
- **Scope_W** — workshop scope; valid only inside the originating workshop's deliverables. Promoted to Scope_S via session-close validation.
- **Scope_S** — session scope; valid across the originating session's wave structure but not yet pinned as canonical. Promoted to Scope_C via cross-session corroboration (typically K=3 instances per M_meta criterion).
- **Scope_C** — canonical scope; pinned as permanent registry/rule item with knowledge.db registration; survives across all future sessions.

**Layer axis** (epistemic class):
- **Layer_A (axiomatic)** — the output is a structural identity / commutator / preserved invariant deriving from substrate axioms; correctness is provable mechanically.
- **Layer_C (categorical)** — the output is a functorial / morphism / categorical mapping between layers; correctness rests on categorical-coherence diagrams.
- **Layer_I (inductive)** — the output is an empirical pattern / methodology rule / cross-corpus observation; correctness rests on empirical instance count + corpus-validation gates.

The 2D map produces 9 cells (`Scope_X × Layer_Y` for `X ∈ {W, S, C}`, `Y ∈ {A, C, I}`), each with promotion-gate criteria.

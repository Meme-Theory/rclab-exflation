## §1. Audit purpose and methodology

### §1.1 Two-layer taxonomy (canonical, NOT invented here)

Verbatim quote from `sessions/framework/registry/cutoff-sqrt-adjudication.md` §1.4 lines 55-66 (R2 lizzi EMERGENCE E3-L from S85 W4 connes x lizzi workshop):

> LAYER 1 (combinatorial-position-on-atlas): determined by Mellin support and observable-cross-classification; cutoff_AL2010 has a unique privileged slot.
>
> LAYER 2 (admissibility-on-axioms): determined by GATE A + GATE B + GATE C numerical tests; cutoff_AL2010 expected to FAIL GATE A.
>
> The two layers are INDEPENDENT structural properties. A regulator can be combinatorially privileged but axiomatically excluded. A regulator can be combinatorially generic but axiomatically admissible.

The independence is the load-bearing structural fact. The audit method tests, per S78-onward statement, whether the cite respected the independence (correctly tagging combinatorial vs admissibility) or violated it (combinatorial-position invoked as admissibility-warrant or vice versa).

### §1.3 4-stage protocol with optional Stage-2.5 sub-tag

Per connes' Re:L4 scaffolding + lizzi's L4 refinement + R2-B CV-7 Stage-2.5 acceptance:

**Stage 1 — Statement enumeration.** Walk the S78-onward record (`sessions/archive/session-78/` through `sessions/archive/session-86/`, plus `sessions/framework/`, plus `computations/` script docstrings, plus `sessions/permanent-results-registry.md` per-entry text) and log every statement S that mentions any element of the trigger-vocabulary:
- Named regulator: {ζ, Zubarev, SDW, cutoff_sqrt, anomaly}.
- Named partition: {F_2, F_4, M, A_5, R_atlas, Atlas_5}.
- Admissibility predicate: {regulator atlas, admissible regulator, K-invariant, R-protected, NOT-R-protected}.

Each S is recorded as a 4-tuple: (source-file, line-number, statement-type, claimed-scope) where `statement-type` ∈ {theorem, corollary, observation, cite, definition, gate-verdict} and `claimed-scope` ∈ {single-regulator, partition, full-atlas}. Stage-1 cardinality estimate: ~250 statements (5 sessions × ~50 atlas-touching statements per session).

**Stage 2 — LAYER tag assignment.** For each enumerated S, classify per the canonical §VII.N L1/L2/L3 stratification (per §1.2 above):

- **L1-axiomatic** (≈ cutoff-sqrt LAYER 2): claim about the regulator's PASS/FAIL under a numerical NCG-axiom test, R-protection number, spectral-action gate, Mellin-strip integrability test. Derived from numerical computation against pre-registered threshold OR from axiom-derivation argument with explicit axiom citation.
- **L3-combinatorial** (≈ cutoff-sqrt LAYER 1): claim about the regulator's position in a partition by Mellin-support / observable-cross-classification / atlas-membership / multiplier-vector. Derivable from f_R definition without numerical PASS/FAIL.
- **L2-substrate-action** (no cutoff-sqrt analog): claim about regulator behavior at τ_fold under three-criterion intersection.
- **L1-with-L2-disclaimer hybrid**: a hybrid type for statements that make a combinatorial claim AND attach an explicit non-evidence-status disclaimer (the THM-L3.1 forward-inference pattern from §VII-B.ZETA-EQUALS-SDW -- a healthy LAYER-1 statement that closes its own LAYER-2 inference channel).

**Stage 2.5 — Sub-classification of L1-axiomatic claims (optional sub-tag; per CV-7 + EM-LZ-2).**

Each L1-axiomatic statement carries a sub-tag distinguishing its derivation method:

- **L1-axiomatic / AXIOMATIC**: derived from NCG axioms A1-A6 + Connes-Marcolli theorems + Connes-Chamseddine 1996 derivations. Warrant: STRONG. Survives across slots/L_max without per-slot re-verification.
- **L1-axiomatic / NUMERICAL**: derived from a pre-registered numerical gate against threshold. Warrant: WEAK. Holds AT the gate's evaluation slot/L_max only; may not survive at other slots.

Examples:
- "ζ is L1-canonical (Connes-Marcolli Thm 1.31)" → L1-axiomatic / AXIOMATIC.
- "the a_2 Seeley-DeWitt coefficient is regulator-independent on the substrate's positive-definite Casimir spectrum (NCG A1 + A6 derivation)" → L1-axiomatic / AXIOMATIC.
- "HP^1 LOOSE max ratio = 2.0 (S86 W1b-T6 PASS)" → L1-axiomatic / NUMERICAL.
- "max_pair_ratio = 9.240e-01 at (ζ, Zubarev) (W4-2 P5 FAIL)" → L1-axiomatic / NUMERICAL.

The Stage-2.5 sub-classification operationalizes warrant-class distinction at the audit-tagging level. It also generates a downstream gate type `S87-LAYER-2-WARRANT-CHECK-{claim}` for any L1-axiomatic / NUMERICAL claim whose warrant-class is contested or whose extension across slots/L_max is unclear (per workshop EM-2 + EM-LZ-2).

**Stage 3 — Cross-tag conflation detection.** For each pair of statements (S_i: L3-combinatorial, S_j: L1-axiomatic) where S_i and S_j concern the SAME regulator OR the SAME partition, check three predicates:

1. **Same-subject test**: do S_i and S_j name the same regulator/partition?
2. **Inference-direction test**: does S_j (L1-axiomatic admissibility claim) cite S_i (L3-combinatorial atlas-membership) as supporting evidence in its derivation chain?
3. **Implication-theorem test**: does the inference from S_i to S_j pass through an EXPLICIT L3 → L1 implication theorem (a §VII.N corollary, a Connes-Marcolli implication, a numerical gate verdict, an axiomatic derivation)?

If predicates 1 and 2 are TRUE and predicate 3 is FALSE, flag CONFLATION RISK on the pair (S_i, S_j). Flagged pairs are queued for remediation at Stage 4.

The S78-onward conflation pattern (per `cutoff-sqrt-adjudication.md` line 250: "treating the canonical 5-atlas as uniform-admissible") decomposes as:

```
(L3-combinatorial fact)  "regulator R ∈ A_5 = {ζ, Zubarev, SDW, cutoff_sqrt, anomaly}"
(L3 → L1 leap)            "therefore R is admissible-on-axioms"
(L1-axiomatic claim)      "every R ∈ A_5 is admissible"
```

The middle step (L3 → L1 leap) is the canonical conflation. It assumes atlas-membership entails axiomatic admissibility, which the S85 W4 workshop converged is FALSE for cutoff_sqrt (L1 GATE A expected FAIL despite L3 unique a_0 occupancy).

**Stage 4 — Remediation tagging.** Each detected conflation receives one of four remediation tags, per `cutoff-sqrt-adjudication.md` §3:

- **REPAIR-IN-SESSION**: the conflation is in a workshop file, plan section, or working-paper that can be patched in the present session by adding the missing L3 → L1 theorem citation OR by inserting an explicit non-evidence-status disclaimer (THM-L3.1 pattern).
- **REPAIR-AT-REGISTRY**: the conflation is in a `permanent-results-registry.md` entry that needs LAYER tag added to its provenance prose. The registry-write hygiene rule (S86 W1c surface, `.claude/rules/epistemic-discipline.md` §"Registry-Write Hygiene") governs the patching mechanic.
- **CARRY-FORWARD-COMPUTE**: a numerical gate is needed to settle whether the conflated statement's L1-axiomatic claim actually holds -- i.e., the L3-combinatorial fact does not yet have a known L3 → L1 implication theorem, and the implication has to be established by computation. Each CARRY-FORWARD-COMPUTE entry generates a `S87-LAYER-2-WARRANT-CHECK-*` gate per workshop EM-2.
- **NO-ACTION**: post-audit re-examination shows the inference does pass through an explicit theorem (e.g., a §VII.N corollary that the audit's first pass missed). False-flag rate is expected to be ~5-10% under strict interpretation in Stages 1-3 and loose interpretation in Stage 4.

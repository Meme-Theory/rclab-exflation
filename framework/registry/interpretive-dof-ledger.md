re-tag, an instrument migration, a falsifier-window move). A rescoping is **scientifically legitimate
only if the rescoped claim is STILL falsifiable** — it must point FORWARD to a test, not backward to a
salvaged result. This is the substrate-first discipline applied to the framework's OWN interpretive
history. Per `feedback_reporting-framing.md`: a model's *flexibility* to absorb any datum is
**unfalsifiability, NOT strength** (the inflation lesson). The load-bearing column below is therefore
the **binding test** — the NEW test that NOW BINDS each rescoped claim. A rescoping without a binding
test is unfalsifiable bookkeeping and is flagged `OPEN-no-binding-test-yet` (cross-ref `evoi-framework.md`
section 6 standing-gap ledger), never left blank.

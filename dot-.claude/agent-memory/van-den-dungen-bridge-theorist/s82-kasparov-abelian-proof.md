## Theorem (formal)

Let pi: E -> M be a Riemannian submersion with compact Lie-group fiber G. Let A_B be an abelian C*-subfactor of C*(G) with Gelfand spectrum X = Spec(A_B) of K-theoretic rank rho in {1, ..., r}. Then the Level-2 R-protection cohomology class in K_0(C_0(M) (x) A_B) VANISHES.

**Corollary**: Level-2 R-protection holds on branch B IFF B is non-abelian (some irrep has dim H_pi >= 2).

## Key proof steps

1. Kasparov factorization: [D] = [D_F] (x)_{C(M)} [D_M] (Paper 01 Main Theorem, VdD 2018).
2. Block decomposition: [D_F] = (+)_B [D_F|_B] (S61 A-TENSOR-61 block-diag, 8.4e-15 exact).
3. Gelfand: A_B abelian ~= C(X). Every irrep of C(X) is 1D (scalar action at a point).
4. K_0(C(S^1)) = Z (rank 1). K_0(C(T^2)) = Z^2 (rank 2). Both generated by rank-1 projections.
5. Level-2 R-protection 2-cocycle c_2(A_B) must be generated by rank->=2 projections (within-sector averaging of scheme asymmetry). For abelian A_B no such class exists.
6. c_2(A_B) = 0 for abelian => Level-2 fails. Non-abelian case: dim H_pi >= 2 irreps exist, M_n(C) embeds, rank-n projection classes present => c_2 != 0 => Level-2 holds.
